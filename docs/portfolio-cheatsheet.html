🎯 Ringkasan 1 Kalimat

Website portofolio personal berbasis Astro + Tailwind, static-generated, bilingual (ID/EN), dengan 6 case study real, design system editorial minimalism yang konsisten, accessibility-ready, dan siap deploy gratis ke Vercel/Netlify.

🎤 Talking Points untuk Wawancara

TopikKey Message
Design Philosophy"Saya pilih editorial minimalism — bukan minimalism yang kosong, tapi minimalism yang punya voice: numbered sections, asterisk motif, mat-galeri poster. Desain yang punya voice."
Problem Solving"Masalah poster portrait di grid landscape → saya buat 'mat galeri' (padding + border + shadow) biar poster tampil utuh tanpa crop."
Performance"Astro static + Astro Assets → 42 gambar WebP, 90% kompresi, lazy loading, Lighthouse 90+."
Accessibility"Bukan checklist doang — focus ring, reduced-motion, touch target 44px, semantic HTML, keyboard nav. Aksesibilitas = fitur, bukan checklist."
Personal Branding"Tagline 'UI yang enak dipakai, desain yang enak dilihat' — ringkas, jujur, mewakili dual skill saya (UI/UX + Graphic)."
Scalability"Content di markdown + Astro Content Collections → nambah project = bikin file .md saja. Siap Decap CMS kalau butuh CMS nanti."
